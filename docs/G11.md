# Checkpointed model graph

The server-only graph uses the shared PostgreSQL checkpointer. Pass the
conversation UUID to `getConversationGraphConfig` for each invocation or
stream. The helper selects the checkpoint thread, sets synchronous durability,
and accepts an optional abort signal. The graph restores history and sends the
full transcript to the configured OpenAI model through the Responses API with
`store: false`.

## Manual verification

In a local TypeScript session with the `react-server` condition and runtime
configuration loaded, use a disposable existing conversation UUID. Submit
only the new user message on each call.

```ts
const graph = getConversationGraph();
const config = getConversationGraphConfig(conversationId);

await graph.invoke({
  messages: [new HumanMessage({ id: "g11-turn-1", content: "My code word is maple." })],
}, config);

await graph.invoke({
  messages: [new HumanMessage({ id: "g11-turn-2", content: "What is my code word?" })],
}, config);

const snapshot = await graph.getState(config);
console.log(snapshot.values.messages);
```

Import `HumanMessage` from `@langchain/core/messages` and the graph helpers from
`lib/server/chat/graph.ts`. Confirm the second answer uses the first turn and
the saved transcript contains both user IDs and both corresponding IDs from
`getAssistantMessageId`.
